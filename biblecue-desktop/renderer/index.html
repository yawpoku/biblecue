Setup Guide

Turn on exactly one output below — enabling several at once sends every detected verse to all of them.

ProPresenter the tricky one

BibleCue triggers a Message in ProPresenter — it doesn't show a message's UUID anywhere in its own interface, so you pull it from the API.

  1. Turn on the Network API. ProPresenter → Preferences → Network, enable it, and note the port (default 1025). Find the ProPresenter machine's local IP (System Settings → Network on Mac, ipconfig on Windows) — that's BibleCue's IP field.
  2. Create the Message. Open ProPresenter's Messages panel (flag icon in the toolbar, or View → Messages), add a message, and build a layout with two text layers. Type the literal text {{VerseText}} into one and {{Reference}} into the other — placeholder tokens ProPresenter fills in live when triggered. Name it something you'll recognize, e.g. "BibleCue".
  3. Get its UUID. With the API on, open in a browser:
    http://<propresenter-ip>:<port>/v1/messages
    This lists every message as JSON. Find yours by "name" and copy the value under "id": { "uuid": "..." }.
  4. Paste the IP, Port, and Message UUID into BibleCue's ProPresenter output (Settings → Outputs) and enable it. Test with the manual verse box on the Live Control page.

Both machines must be on the same network. If ProPresenter returns an HTTP 404 on trigger, the message was likely deleted/recreated since — recreating always issues a new UUID, even with the same name. Redo step 3.

EasyWorship

EasyWorship doesn't publish a live "push a slide" API the way ProPresenter does, so this output writes the verse to a plain text file instead — same mechanism as the generic Text File output, with its own toggle and default path so it's easy to tell apart.

  1. Pick a path. Enter any file path in the EasyWorship output's Path field (e.g. C:\BibleCue\easyworship_verse.txt). BibleCue creates/overwrites it on every detection with the verse text on the first line and the reference on the second.
  2. Point EasyWorship at it. Exact steps vary by EasyWorship version — look for a way to display live/auto-refreshing text from a local file, such as the Announcements module's text/ticker source (Media → Announcements in recent versions) set to read that path and refresh on an interval. If your version has no such feature, a free "watch folder" or hotkey plugin from EasyWorship's marketplace can usually bridge a text file into a Custom Slide.
  3. No live-text feature at all? Use the Clipboard output instead — it copies each verse the instant it's detected, ready to paste into a Custom Slide by hand.

OBS Studio

Requires a text source already added to your OBS scene (its exact name goes in BibleCue's Text Source field).

  1. In OBS: Tools → WebSocket Server Settings, enable the server, note the port (default 4455) and click "Show Connect Info" for the password.
  2. In BibleCue's OBS Studio output: IP 127.0.0.1 if BibleCue and OBS run on the same machine (otherwise OBS's local IP), the port, the password, and the exact text source name.

HTTP Webhook

Enter any URL that accepts a POST with JSON body {"verse","reference","translation"} — a EasyWorship/Proclaim integration, a Zapier/Make webhook, or your own script.

Text File

Enter a file path (e.g. C:\verse.txt or /Users/you/verse.txt). BibleCue overwrites it with the verse text and reference on every detection — point a lower-third tool, OBS's "Read from file" text source, vMix, etc. at that path.

TCP Raw

Enter the IP and port of a device listening on a plain TCP socket (legacy broadcast character generators, custom scripts). BibleCue sends "<verse text> — <reference>\n" as UTF-8 — no protocol beyond that.

Clipboard

No setup — copies "<verse text> — <reference>" to the system clipboard on every detection. Paste it into anything.

NDI

Sends the verse as a live 1920×1080 video source over your network — no file bridge, no plugin on the receiving side. Give it a Stream Name and enable it; any NDI receiver (OBS with the NDI plugin, vMix, NDI Studio Monitor) will see it appear by that name. It's rendered using whatever you set on the Theme page — background, fonts, colors, and alignment all carry over.

Requires the NDI runtime to be installed on this machine. If it's missing, the toggle simply does nothing rather than erroring — install NDI Tools from ndi.video and restart BibleCue.
